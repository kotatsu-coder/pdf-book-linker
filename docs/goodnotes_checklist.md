# Goodnotes 実機確認表

作成した PDF が Goodnotes（iPad）でどう動くかを確かめるための表です。端末やアプリの版によって結果が変わる可能性があるので、確かめた環境と結果を記録してください。まずはデモ本（`tools/make_demo_book.py`）で試すと、本のデータを使わずに確認できます。

実施日：＿＿＿＿　Goodnotes の版：＿＿＿＿　iPadOS の版：＿＿＿＿　iPad の機種：＿＿＿＿

取り込み方法（ファイルアプリから開く / Goodnotes 内から読み込む など）：＿＿＿＿

## 準備

1. デモ本を作り、リンクを付ける。

   ```bash
   uv run python tools/make_demo_book.py -o work/demo.pdf
   uv run pdf-book-linker build work/demo.pdf -o output/demo_linked.pdf
   ```

2. `output/demo_linked.pdf` を iPad に送り、Goodnotes に新しいノートとして読み込む。
3. 元のファイルは残し、再出力するときは別名にする。
4. PDF のしおり（アウトライン）と、Goodnotes 独自のブックマークは別のものとして記録する。

## 確認項目

|番号|操作|確かめること|結果|
|---|---|---|---|
|1 目次|目次の各行のタイトル部分と数字部分をそれぞれ押す|該当ページへ移動するか。点線や空白部分が反応しないか|＿＿＿＿|
|2 章扉の小目次|WORLD 1〜3 の扉の各行を押す|各 STAGE の最初のページへ移動するか|＿＿＿＿|
|3 索引|索引の1行に並んだ複数の数字を、1つずつ押す|数字ごとに別のページへ移動するか|＿＿＿＿|
|4 本文の参照|本文中の「○ページ参照」を押す|文字の範囲だけが反応し、正しいページへ移動するか|＿＿＿＿|
|5 ナビボタン|←← / ← / → / →→ を、章の途中・章の先頭・章扉で押す|←← 目次、← 今の章の先頭（章扉では一つ前の章）、→ 次の章、→→ 索引|＿＿＿＿|
|6 しおり|アウトライン画面を開き、階層と順番を確認して選ぶ|PDF 由来の階層が表示され、選ぶと移動するか|＿＿＿＿|
|7 閲覧 / 編集モード|閲覧モードと、ペンを選んだ状態でそれぞれリンクを押す|どのモードで、どの操作で移動できるか|＿＿＿＿|
|8 手書きの後|リンクの近くに手書きを加え、保存して開き直してから押す|手書きが残り、リンクも動くか|＿＿＿＿|
|9 再出力|PDF として別名で書き出し、別のノートに読み込んで 1〜6 を再確認|リンクとしおりが残っているか|＿＿＿＿|
|10 大きな本|数百ページ以上の本で作った PDF を読み込む|読み込み時間、ページ送りの引っかかり、停止の有無|＿＿＿＿|
|11 回転・見開き|端末の向きを変える。見開き表示があれば切り替える|押した場所とリンクの位置がずれないか|＿＿＿＿|

うまくいかなかった場合は、項目番号、操作、期待した移動先、実際の移動先、表示モード、再出力の前か後かを記録してください。

## 分かっている制約

- Goodnotes には「前の場所に戻る」機能がないため、リンクで移動した後に元の場所へ戻るボタンは作れません。
- ナビボタンは PDF に描いた線なので、印刷すると出ます。
